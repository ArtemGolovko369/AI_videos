# Общий формат TikTok-роликов

## Технические параметры
- Вертикаль **9:16** (референсы — 576×1024; для своих видео лучше 1080×1920).
- Длительность: 60–90 сек для динамичного формата, до 3–3,5 мин для сюжетной истории.
- Голос за кадром (рассказчик) + фоновая музыка/эмбиент + звуковые эффекты.
- Смена кадра каждые 1–3 секунды: статичная картинка с лёгким движением камеры (зум, панорама, покачивание) — этого достаточно, полноценная анимация не обязательна.

## Субтитры (общий принцип)
- Крупный жирный шрифт без засечек, **ВСЕ ЗАГЛАВНЫЕ**.
- Белые буквы с тёмной обводкой или тенью — читаются на любом фоне.
- Расположение — нижняя середина кадра (примерно 60–75 % высоты), выше нижней панели TikTok.
- Показываются по 1–4 слова синхронно с голосом.
- Ключевые слова выделяются цветом (жёлтый — акцент, красный — опасность/мат/«навсегда», зелёный — деньги/успех).

## Безопасные зоны
- Справа внизу — иконки TikTok (лайк, комменты) и водяной знак: важное туда не ставить.
- Верх ~10 % — под шапку/интерфейс приложения; туда удобно класть свой «HUD» (часы, счёт).

## Структура ролика
1. **Хук (0–3 сек)** — сразу результат/интрига («один заработал 10 000, другой — нет», «она умирает каждую ночь»).
2. **Завязка** — правила, условия, таймер.
3. **Развитие** — 3–6 коротких сцен, нарастание.
4. **Поворот / кульминация.**
5. **Концовка с вовлечением** — вопрос зрителю или выбор кнопками («Решать вам»), чтобы писали в комментариях.
6. Финальная заставка с ником автора.
