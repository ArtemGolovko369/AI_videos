# Анимации для TikTok-роликов

Описание приёмов движения, подсмотренных в двух референсах. **Не копия**, а набор техник с примерными таймингами, чтобы собирать свои видео в CapCut, After Effects, Premiere, Rive или в коде (Remotion / Python + ffmpeg).

Главный вывод: в обоих роликах **почти нет «настоящей» анимации**. Всё держится на статичных иллюстрациях + 3–5 слоях простого движения (рот, глаза, камера, частицы, интерфейс). Это дёшево делать и легко генерировать.

---

## 1. Базовые принципы

| Параметр | Стиль 1 — драма | Стиль 2 — комедия |
|---|---|---|
| Частота смены сцен | 1 сцена ≈ 5–20 сек (≈10 склеек на 3,5 мин) | 1 сцена ≈ 2–4 сек (≈20+ склеек на 80 сек) |
| Переходы | Плавное растворение (crossfade 0,4–0,8 сек) | Жёсткая склейка, иногда «вспышка» или шторка |
| Камера | Медленный наезд/отъезд, почти незаметный | Резкие зумы, тряска, «рывки» |
| Плавность (easing) | ease-in-out, мягко | ease-out с отскоком (back / elastic) |
| Кадров персонажа | 2–3 позы рта + моргание | 3–4 позы рта + 3–5 эмоций лица |
| FPS «внутренней» анимации | 6–8 к/с (как в рисованном мультике) | 8–12 к/с |

> Совет: рендерить видео в 30 к/с, а позы персонажа менять с шагом 3–4 кадра — получается «рисованная» дёрганость, которая выглядит стильно, а не дёшево.

---

## 2. Анимация персонажей

### 2.1. Липсинк (движение рта)
- Рисуем 3 формы рта: **закрыт**, **приоткрыт**, **широко открыт** (в комедии + 4-я «орущая» с языком).
- Переключаем по громкости голоса: тишина → закрыт, средне → приоткрыт, пики → открыт.
- В драме рот шевелится только у говорящего героя и скромно; в комедии рот открывается на пол-лица.
- Автоматизация: Adobe Character Animator, Live2D, плагины «audio → keyframes», или скрипт: амплитуда аудио каждые 1/10 сек → номер спрайта.

### 2.2. Моргание
- 2 кадра: открытые глаза → закрытые (≈80–120 мс) → открытые.
- Интервал случайный, 2–5 сек. Не синхронизировать у двух персонажей.

### 2.3. Смена эмоций
- Меняется только голова/лицо, тело остаётся тем же слоем.
- Комедия: радость (глаза-дуги ^^) → самодовольство (полуприкрытые веки) → шок (огромные зрачки) → грусть (брови домиком, слеза). Переключение мгновенное, на ударном слове.
- Драма: нейтральное лицо → лёгкая улыбка → слёзы (тонкие голубые дорожки, медленно «стекают» 1–2 сек).

### 2.4. «Дыхание» и idle
- Тело слегка масштабируется по вертикали на 1–2 % с периодом 2–3 сек — персонаж «живой», даже когда стоит.
- Комедия: подпрыгивание на ударных словах (вверх 20–40 px за 0,1 сек и обратно с отскоком).

### 2.5. Жесты (минимальные)
- Руки — отдельный слой, поворачиваются вокруг плеча на 10–30°: поднять руки от радости, держать предмет у лица.
- Ходьба: 2–4 кадра цикла + движение всего персонажа по горизонтали; можно вид со спины — тогда ноги почти не нужны.

## 3. Камера

| Приём | Как сделать | Где использовать |
|---|---|---|
| **Медленный наезд (Ken Burns)** | Масштаб 100 % → 106–110 % за всю сцену, linear/ease-in-out | Драма: почти каждая сцена |
| **Медленная панорама** | Сдвиг фона на 3–5 % ширины | Улица, город, кинозал |
| **Резкий зум на лицо** | 100 % → 180–250 % за 0,15 сек, ease-out | Комедия: шок, крик, «глаза навыкате» |
| **Тряска (shake)** | Случайный сдвиг ±5–15 px, 0,2–0,4 сек | Комедия: удар, ор, проигрыш; драма — авария |
| **Параллакс** | Фон движется медленнее переднего плана (2–3 слоя) | Ночная улица, крупные планы в драме |
| **Фокус-виньетка** | Затемнение краёв нарастает 0 → 60 % | Драма: напряжённые моменты, крупный план предмета |

---

## 4. Переходы между сценами

### Стиль 1 (драма)
- **Растворение (crossfade)** 0,4–0,8 сек — основной переход. Удобно для «двойной экспозиции»: лицо героини проступает сквозь часы.
- **Затемнение в чёрный** 0,5 сек — конец «дня» / сброс петли.
- **Мигание света** — фонарь или лампа гаснет-загорается 2–3 раза перед важным поворотом.

### Стиль 2 (комедия)
- **Жёсткая склейка** по ударному слову (лучше всего — точно на слоге).
- **Белая вспышка** 2–3 кадра — «бах», выигрыш.
- **Разделение экрана** — кадр режется пополам (вертикально или по диагонали), половинки въезжают с разных сторон за 0,2 сек.
- **Шторка-зум** — камера влетает в предмет (экран, окно) и следующая сцена начинается «внутри».

## 5. Частицы и эффекты окружения

| Эффект | Описание | Тайминг |
|---|---|---|
| **Падающие купюры** | 5–15 зелёных прямоугольников, летят сверху вниз с вращением ±30° и покачиванием | 1–2 сек полёта, спавн каждые 0,1–0,2 сек |
| **Дождь** | Тонкие диагональные полоски, полупрозрачные, тёмно-синий фон | Бесконечный цикл 0,5 сек |
| **Перекати-поле** | Круглый спрайт катится по земле с вращением | 2–3 сек через кадр |
| **Вращающиеся лучи** (sunburst) | Фон-лучи медленно вращаются вокруг центра | 1 оборот за 20–40 сек |
| **Звёздочки / блёстки** | Мигающие 4-конечные звёзды, scale 0 → 1 → 0 | 0,5 сек каждая |
| **Свечение (glow)** | Пульсация яркости тёплого источника 90–110 % | Период 2–3 сек |
| **Пар / дыхание / пыль** | Слабые полупрозрачные пятна, поднимаются вверх | Драма, ночные сцены |
| **Сердечко / эмодзи над головой** | Выскакивает с отскоком, покачивается | 0,3 сек появление |

## 6. Анимация интерфейса (HUD)

### 6.1. Цифровые часы (драма)
- Время меняется скачком от сцены к сцене (23:30 → 23:41 → 23:57 → 23:59).
- На смене — короткий «глитч»: цифры мерцают 2–3 кадра, или старое значение уезжает вверх, новое въезжает снизу.
- Счётчик «ДЕНЬ N» в момент перезапуска петли: вспышка красным + +1.

### 6.2. Стрелочные часы (крупный план)
- Секундная стрелка движется **рывками** (1 шаг в секунду), минутная — плавно.
- Перед полночью: стрелки сходятся на XII, тиканье усиливается, лёгкое покачивание часов на цепочке (маятник ±3°, период 1,5 сек).

### 6.3. Счётчики денег (комедия)
- **Прокрутка числа (count-up)**: значение меняется от A до B за 0,5–1,5 сек с ease-out ($9 061 → $9 630 → $9 883 → $10 000).
- Обратный отсчёт у проигравшего: число уменьшается, при переходе в минус — цвет на **красный** + короткая тряска табло.
- **Плашки «+$…» / «−$…»**: выпрыгивают (scale 0 → 115 % → 100 %, 0,25 сек) и слегка повёрнуты на ±5–8°.

### 6.4. Таймер обратного отсчёта
- Цифры ЧЧ:ММ:СС меняются каждую секунду; при «перемотке времени» — быстрая прокрутка с размытием.
- Последние секунды: таймер пульсирует (scale 100 → 108 %) и краснеет.

### 6.5. Окна приложений / чатов
- Окно появляется: scale 80 % → 100 % + fade-in, 0,2 сек, лёгкий отскок.
- **Печать текста**: по 1 символу каждые 30–60 мс, мигающая каретка «|» (период 0,5 сек).
- Окна-виджеты (код, магазин, график) выезжают каскадом с задержкой 0,1–0,15 сек друг за другом.
- Столбцы графика растут снизу вверх по очереди.

### 6.6. Таблички-заголовки и стикеры
- Появление «штампом»: scale 150 % → 100 % за 0,12 сек + тряска 0,1 сек.
- Или «pop»: 0 → 110 % → 100 %, ease-out-back.
- В покое — лёгкое покачивание (rotation ±2°, период 2 сек).

### 6.7. Кнопки выбора (финал драмы)
- Кнопки появляются по очереди с fade + сдвигом вверх на 10 px.
- Мягкая пульсация обводки (свечение 0 → 100 % → 0), намёк «нажми».

## 7. Анимация субтитров

### Драма
- Текст **накапливается по словам**: «ТАМ СТОЯЛ» → «ТАМ СТОЯЛ МОЙ» → «ТАМ СТОЯЛ МОЙ БРАТ.» — фраза строится, пока звучит голос.
- Новое слово появляется мягко (fade 0,1 сек), без прыжков.
- После фразы — пауза 0,3–0,6 сек, затем блок полностью сменяется.
- Ключевое слово в конце фразы — цветом (жёлтый/красный).

### Комедия
- Блок из 2–5 слов выскакивает целиком «поп-ом» (scale 80 → 105 → 100 %, 0,15 сек).
- Слово-панчлайн окрашивается в цвет в момент произнесения.
- На крике — текст трясётся или увеличивается.

---

## 8. Звук, привязанный к анимации

| Событие | Звук |
|---|---|
| Смена цифр часов / счётчика | тик, щелчок, «кассовый аппарат» |
| Появление плашки / стикера | «поп», «бульк» |
| Печать текста | клавиатура |
| Падение денег | шелест + «дзынь» |
| Проигрыш | грустный тромбон, гром |
| Петля времени / перезапуск | гул, перемотка, удар колокола |
| Резкий зум | «вжух» (whoosh) |

> Каждое визуальное событие = свой короткий звук. Это половина «динамичности» комедийного стиля.

## 9. Готовые рецепты сцен

### «Достаёт артефакт» (драма, ~4 сек)
1. Тёмный фон с тёплым свечением в центре, glow пульсирует.
2. Руки с предметом въезжают снизу (0,6 сек, ease-out).
3. Медленный наезд 100 → 108 %.
4. Субтитры накапливаются по словам.
5. Растворение в следующую сцену.

### «Перезапуск петли» (драма, ~2 сек)
1. Стрелки сходятся на 12 → тиканье затихает.
2. Белая вспышка 3 кадра → затемнение в чёрный 0,5 сек.
3. Появляется та же сцена, что в начале; счётчик дней +1 с красной вспышкой.

### «Хук с табло» (комедия, ~3 сек)
1. Фон-лучи вращаются, два героя стоят рядом (idle).
2. Табло: у одного число бежит вверх, у другого вниз до минуса (красный + тряска).
3. Победитель — руки вверх и прыжки, проигравший — эмоция грусти.
4. Склейка на split-screen: слева дождь из денег, справа дождь из капель.

### «Абсурдная сцена-мем» (комедия, ~2 сек)
1. Жёсткая склейка на неожиданный фон (пустыня, синтвейв, ферма).
2. Табличка-заголовок «штампом» сверху.
3. Персонаж в костюме, рот орёт, через кадр катится перекати-поле.
4. Резкий зум на лицо в конце фразы.

## 10. Анимации стиля «Что если…» (стиль 3)

| Параметр | Значение |
|---|---|
| Частота смены сцен | 1 сцена ≈ 2–4 сек, ≈25 кадров на 65 сек |
| Переходы | Только мягкие: быстрое растворение 0,2–0,3 сек или проезд камеры — жёстких склеек почти нет |
| Камера | Медленные наезды и панорамы, вид от первого лица (рука в кадре) |
| Плавность | ease-in-out, спокойная |

### Постепенное обесцвечивание мира
- Глобальный слой «Насыщенность»: от 100 % в начале до 0–10 % к финалу, шагами между сценами.
- Внутри сцены — локальная анимация: предмет теряет цвет за 0,5–1 сек (синий → серый), можно с «волной» от края к краю.
- Исключение — один акцентный объект, который остаётся цветным и светится.

### Светящийся объект
- Пятно/точка с glow: пульсация яркости и размера (100 → 115 %, период 1,5–2 сек).
- На сюжетном моменте «оно стало больше» — scale ×1,5–2 за 1 сек с усилением свечения.

### Караоке-субтитры
- Вся фраза появляется приглушённой (opacity 40–50 %).
- Каждое слово переходит в 100 % белый в момент произнесения (0,05–0,1 сек).
- Тематическое слово дополнительно окрашивается в цвет (синий с белой обводкой) и чуть увеличивается (105 %).
- Смена фразы — быстрый fade 0,15 сек.

### Телефон с новостью
- Смартфон въезжает снизу в руке (0,4 сек, ease-out).
- Иллюстрация на экране меняется в реальном времени: глобус по шагам теряет цвет, таймер считает (0:00 → 0:01).
- Лёгкое покачивание руки (±2°), будто держит живой человек.

### Мелкие «живые» движения
- Машины проезжают по дороге (линейно, 2–3 сек через кадр).
- Моргание и лёгкое движение рта у говорящих персонажей.
- Аватар-кружок «мысли» появляется pop-ом рядом с головой.
- Массовка: персонажи стоят неподвижно, затем **одновременно** поворачивают головы к камере (смена спрайта в один кадр) — главный жуткий момент.

### Титул серии
- Затемнение в чёрный 0,5 сек → точка света загорается → название проявляется (fade + лёгкий наезд), «СЕРИЯ N» — с задержкой 0,3 сек. Медленно летающая пыль на фоне.

## 11. Чек-лист перед публикацией
- [ ] В каждой сцене что-то движется (минимум: камера или моргание).
- [ ] Липсинк совпадает с голосом.
- [ ] Субтитры не перекрывают лицо и не уходят под иконки TikTok.
- [ ] У каждого «ударного» события есть звук.
- [ ] Первые 3 сек — самое динамичное место ролика.
- [ ] Переходы в одном стиле (не смешивать мягкие растворения с вспышками без причины).
