# Файлы: персонажи, визуал, интерфейс

Справочные описания для создания собственных вертикальных видео (TikTok / Reels / Shorts) на основе двух проанализированных роликов-референсов.

> **Правило:** это не копия референсов, а примерное описание *подхода*. Имена, внешность, сюжеты, надписи и названия брендов в своих видео меняем. Берём только приёмы: стиль рисовки, ритм, композицию, тип интерфейса.
