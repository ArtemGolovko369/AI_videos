# «Рядом с работой или вдвое дешевле?» — сценарий 1 из «Что выберешь? — 3 сценария»

Стиль 4 «Что выберешь…?». Вертикаль 9:16, 1080×1920, 30 к/с, **75,6 сек**.

- **Готовый ролик:** `arenda_ryadom_ili_deshevle.mp4`
- **Обложка:** `cover.png`
- **Голос:** vidIQ, **Nikolay** (`3EuKHIEZbSzrHGNmdYsx`) — носитель русского. В документе был указан Liam, но он англоязычный и читает с акцентом; для серии из трёх роликов этот же голос нужно оставить в сценариях 2 и 3.
- **Музыка:** vidIQ, бодрый lo-fi-поп без слов, 110 BPM (`audio/music.mp3`), на ~13 дБ тише голоса.
- **Звуки** (поп, касса, вжух, будильник, метро, тромбон, штамп, перелистывание) синтезированы в `tools/sfx.py`.
- **Сведение:** голос + музыка + эффекты → −14 LUFS.

## Как пересобрать
```
python3 tools/timings.py          # тайминги слов (по строкам vidIQ) + огибающая для липсинка
python3 tools/sfx.py              # дорожка эффектов
node tools/render.js preview 12.5 # PNG одного кадра
node tools/render.js all          # все кадры в build/frames
# сведение и сборка — команды ffmpeg в истории коммита / ниже
ffmpeg -i audio/voice.mp3 -i audio/music.mp3 -i build/sfx.wav -filter_complex "[0:a]aresample=44100,apad=pad_dur=3[v];[1:a]volume=0.16,afade=t=out:st=73.5:d=2[m];[2:a]volume=0.55[s];[v][m][s]amix=inputs=3:normalize=0:duration=first,atrim=0:75.6,loudnorm=I=-14:TP=-1.5:LRA=11[a]" -map "[a]" build/mix.wav
ffmpeg -framerate 30 -i build/frames/%05d.jpg -i build/mix.wav -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest arenda_ryadom_ili_deshevle.mp4
```
Все сцены — функция `render(t)` в `tools/scene.html` (SVG): карточки вариантов, выбор героев, утро Тёмы и Вики, подсчёт, кошелёк Вики, диван, курс и оффер, итог VS, финал с диагональю.
